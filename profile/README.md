### 📌 Aturan Singkat Buat Teman-Teman Kelas
1. **Folder / Branch:** Kalau ngerjain tugas kelompok barengan, buat branch sendiri atau pastikan tidak menimpa pekerjaan teman tanpa konfirmasi.
2. **Jangan Upload Kredensial:** Hindari mengunggah token API, password database pribadi, atau file `.env` ke repo publik.
3. **Bantu Review:** Kalau ada teman yang bikin Pull Request, bantu cek bareng-bareng sekalian belajar Git workflow.
